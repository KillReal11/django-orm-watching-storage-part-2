# Пульт охраны банка

Это внутренний репозиторий для сотрудников банка "Сияние". Если вы попали в этот репозиторий случайно, то вы не сможете его запустить, т.к. у вас нет доступа к БД, но можете свободно использовать код верстки или посмотреть как реализованы запросы к БД.

Пульт охраны - это сайт, который можно подключить к удаленной базе данных с визитами и карточками пропуска сотрудников банка.

### Как установить

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```
Для подключения к базе данных нужно настроить переменные окружения в файле [settings.py](settings.py). Создайте файл `.env` в корневой директории проекта и заполните его согласно инструкции ниже.

| Переменная  | Описание |
| ------------- | ------------- |
| SECURITY_DB_HOST  | Адрес хоста с базой данных  |
| SECURITY_DB_PORT  | Порт для подключения к базе данных  |
| SECURITY_DB_NAME  | Имя базы данных  |
| SECURITY_DB_USER  | Имя пользователя базы данных  |
| SECURITY_DB_PASSWORD  | Пароль пользователя базы данных  |
| SECURITY_SECRET_KEY  | Секретный ключ Django   |
| ALLOWED_HOSTS  | Список хостов, которые сайт может обслуживать |
| DEBUG  | Режим отображения ошибок на сайте   |

Все переменные окружения имеют префикс `SECURITY_` для группировки настроек безопасности и подключения к базе данных. Настройки `SECURITY_DB_*` требуются для корректного подключения к базе данных. `SECURITY_SECRET_KEY`  в Django используется для криптографической подписи данных и защиты данных проекта. 

`ALLOWED_HOSTS` является защитой от HTTP Host Header Attacks.

`DEBUG` использует значения `True`/`False` для выбора режима отображения ошибок: детализированный для отладки или упрощенный для пользователя соответственно.
